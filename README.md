# Bluesky Profile Parser & Sender Bot

Telegram-бот для автоматизации работы с социальной сетью Bluesky. Позволяет искать профили по ключевым словам и выполнять массовую рассылку личных сообщений (DM).

## 🚀 Основные возможности

### 🔍 Парсер (Parser)
- Поиск профилей по ключевым словам в постах.
- Фильтрация по количеству подписчиков.
- Поиск профилей только с открытыми личными сообщениями (DM).
- Выгрузка результатов в формате TXT.
- Поддержка выбора языка поиска.

### 📤 Сендер (Sender)
- Массовая рассылка сообщений в Bluesky.
- Загрузка списка целей из TXT файла (ссылки на профили).
- Поддержка кликабельных ссылок в сообщениях.
- Использование собственных аккаунтов Bluesky через App Passwords.
- Отслеживание прогресса и статистика отправки.

### 💎 Монетизация и управление
- **Система подписок:** Раздельные тарифы для парсера и сендера.
- **Crypto Payment:** Интеграция с CryptoBot для автоматического пополнения баланса.
- **Реферальная система:** Бонусы за приглашение новых пользователей.
- **Админ-панель:** Управление пользователями, выдача баланса/подписок, рассылка объявлений и черный список.

## 🛠 Технологии
- **Python 3.10+**
- **aiogram 3.x** (Telegram Bot API)
- **aiohttp** (Асинхронные HTTP запросы к Bluesky API)
- **SQLite** (База данных)

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш-аккаунт/bluesky-bot.git
   cd bluesky-bot
   ```

2. **Установите зависимости:**
   ```bash
   pip install aiogram aiohttp
   ```

3. **Настройте конфигурацию:**
   Создайте файл `config.py` (на основе существующего или используйте переменные окружения) и заполните следующие данные:
   - `BOT_TOKEN`: Токен вашего Telegram бота.
   - `BLUESKY_HANDLE` / `BLUESKY_APP_PASSWORD`: Технический аккаунт для работы парсера.
   - `CRYPTO_BOT_TOKEN`: Токен от CryptoBot.
   - `ADMINS`: Список ID администраторов.

4. **Запустите бота:**
   ```bash
   python main.py
   ```

## ⚠️ Важное примечание
Файл `config.py` содержит конфиденциальную информацию и добавлен в `.gitignore`. Никогда не публикуйте свои токены и пароли в открытый доступ.
